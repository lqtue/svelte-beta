The OCR pipeline, read as a ledger of choices

Every stage of the OCR pipeline is a decision someone made under a real constraint — cost, a faded 1882 map, Cloudflare's missing child_process, a schema that never grew a legend column. This audits each choice against the road not taken, and rates it keep, tune, or fix. Rated from source at HEAD; anchors are file:line.

Top risks — ranked by blast radius, fix these first

  1. Four coordinate conventions, no single normalization point
    Schema says 0–1000 normalized; V1–V3 prompts say tile pixels; the retry-hint says pixels; local_vision returns raw image px; SCOUT uses float bboxes, extraction uses int. Which convention a row is in depends on which prompt version ran — not schema-enforceable. Silent geometry corruption.
  2. status never gates derived reads
    legend-points and join_labels both read every row regardless of status → rejected and un-reviewed pending extractions still project onto the public map, and human text_validated corrections are ignored. HITL rejections don't propagate. Highest-value single fix.
  3. RLS UPDATE open to any authenticated user
    Migration 042's UPDATE policy allows any authenticated role, not just admins. The API enforces admin; the DB does not. Authz depends on the app route being the only path in.
  4. Cache can serve a result from a different sampling regime
    Cache key = SHA256(image+prompt+model+manual SCHEMA_VERSION). It omits temperature, max_output_tokens, and system_instruction. Extraction runs at default (nondeterministic) temperature, and SCHEMA_VERSION is a hand-bumped string already drifted from the real schema. Stale/mismatched hits served silently.
  5. Default extraction path silently ignores the versioned prompt
    extract_labels_sequence takes no user_prompt, so in row-sequence mode (the default) the whole --prompt v8 selection is dead — only SYSTEM_PROMPT plus a hard-coded inline prompt drives it, and that inline prompt uses the rejected V4 "assemble the full label" philosophy V6+ abandoned for hallucination.
  6. Malformed-JSON retry drops the image
    On a parse failure the one retry re-sends contents=[retry_prompt] with no image, asking the model to re-emit JSON it can no longer see — and the retry hint hard-codes the old schema shape (px bbox, no frame_idx, no hydrology).
  7. Manual bboxes collide on the unique key
    Manual POST defaults tile_x/y=0, text=''; the unique index is (map_id,run_id,tile_x,tile_y,text). Draw two empty boxes in a run → the second insert fails on (…,0,0,'').
  8. Fire-and-forget spawn discards all output
    Trigger route spawns detached with stdio:'ignore' and returns 202. A crashed run is indistinguishable from a running one; operators learn of failure only from absent DB rows.

Trade-off

Tune
ocr.py:dedup_items:1096 (IoU 0.15 + 1.5× max-dim)
Chose

Trade-off

Trade-off
