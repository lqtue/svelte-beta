Vietnam Map Archive · system structure

Coarse to fine, OCR-seeded, joined by level

A color pre-pass triages pixels for free. Then OCR reads the labels and seeds the segmenter: its points prompt SAM2, which segments coarse first (blocks, rivers) then fine (buildings) inside those masks. Labels rejoin geometry by matching OCR category to footprint level — then the existing Allmaps warp carries it all to geographic coordinates.

Build order — laziest path that holds

  1. 1 Level-aware label ↔ footprint join + FK.
    Nullable footprint_id on ocr_extractions (mig 049). Smallest-containing polygon, disambiguated by OCR category ↔ footprint level (number→building, name→block/street). Ships on existing OCR + seg. Ray-cast PIP, ~50 lines + assert check.
  2. 2 Color pre-pass.
    numpy over the full image → auto-fill the Triage priority grid (currently manual) + a near-free water/veg mask feeding the coarse pass + blank-tile skip to cut API cost. Uses existing scipy, zero new dep.
  3. 3 Neighbor-window OCR batching.
    Tile + neighbors in one multi-image Gemini call — resolves cross-tile word splits, retires stitch/dedup (~407 lines). Trade: more tokens/call.
  4. 4 OCR points → SAM2 prompts (coarse→fine).
    Feed OCR centroids as MapSAM2 point prompts; run blocks/rivers first, buildings inside those masks. Area features get labels at birth — shrinks the join to linear-only. Bigger change; needs the seg pass reworked to accept prompts.
  5. 5 Eval harness.
    ICDAR-MapText CharACC + box IoU (OCR); IoU + COCO PQ vs held-out traces (seg). Gates the fine-tune; measures whether a gazetteer is worth it.
  6. 6 Gazetteer link + hallucination guard. — deferred
    Same join pass, folded in later once the eval harness can show the gain. Source decided empirically.
  7. 7 Trace HITL exports → LoRA shot set. — deferred
    10-shot floor × 2 styles (French-colonial, US-AMS). Needs the eval harness to prove it beats the U-Net baseline.
